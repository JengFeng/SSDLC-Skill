# 部署階段技能規範 (05_deployment)

本技能定義了開發團隊在部署階段的標準作業程序（SOP）與代理職責。

## 一、 代理人職責規範

### 1. Planner (規劃代理)
*   **任務**：設計部署步驟、環境設定，並規劃若部署失敗時的 5 分鐘快速回滾（Rollback）方案。
*   **驗收標準**：部署清單中必須定義明確的 Rollback 步驟（如還原 MSSQL 資料庫與 Git 程式碼至指定 Baseline）。

### 2. Generator (執行代理)
*   **任務**：
    1.  執行編譯與自動化建置。
    2.  對編譯產出的二進位檔案進行數位簽章寫入（C# 環境依照 `docs/重新編譯(自動加入數位簽章).md` 執行）。
    3.  產出建置清單 `outputs/build_manifest.json`，計算並記錄所有組態項目檔案的 SHA-256 雜湊值（Hash）。
    4.  產出數位簽章與建置結果報告 `outputs/signature_status.json`。

### 3. Evaluator (審查代理)
*   **任務**：型態完整性與可用度驗證。
*   **審查重點**：
    *   **組態基準比對**：重新計算當前實體檔案的 SHA-256 雜湊值，並比對 `build_manifest.json` 中的紀錄，確保檔案未被外部篡改或遺漏。
    *   **可用度核對**：自動呼叫 Health Check API，執行煙霧測試（Smoke Test），確認部署後的系統基本功能正常。
    *   **數位簽章校驗**：驗證二進位檔的證書簽章是否有效。

---

## 二、 輸入與輸出規範

*   **輸入路徑 (`inputs/`)**：存放此階段人類輸入的環境配置參數與金鑰。
*   **輸出路徑 (`outputs/`)**：
    *   `build_manifest.json`：建置組態項目清單。
    *   `signature_status.json`：數位簽章驗證結果。
