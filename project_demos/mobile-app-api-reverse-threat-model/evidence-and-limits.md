# 證據與限制

## 證據分類

| ID | 分類 | 本案例可支持的陳述 | 公開內容處理 |
|---|---|---|---|
| OBS-01 | 靜態程式觀察摘要 | 授權與登入交換流程涉及帳戶驗證、權杖檢查及網站工作階段建立。 | 移除專案、檔案、類別、端點及行號。 |
| OBS-02 | 靜態程式觀察摘要 | 資源選取與帳戶可用資源清單有關；請求中的資源識別值是否被驗證是需確認事項。 | 不公開實際資源名稱與資料庫識別。 |
| DOC-01 | 介接文件摘要 | 外部 App 流程包含首次授權、權杖更新及登入交換等步驟。 | 不附原始介接文件或真實回呼網址。 |
| INF-01 | 威脅分析推論 | 權杖重放、回呼導向與資源授權不足是依資料流提出的候選威脅。 | 標為待核實情境，不宣稱已確認漏洞。 |
| UNK-01 | 未知 | 正式部署、執行時路由、實際回應、資料庫約束、網路控制、權杖設定及測試結果。 | 保留為待確認，不以推論補成事實。 |

## 驗證狀態

- 工作方式：靜態程式／文件證據整理與威脅建模。
- 未執行：原始系統、建置、測試、部署、正式服務請求或資料庫連線。
- 未確認：業務規則、回呼白名單、權杖保護設定、資源授權、速率限制、日誌內容及實際網路邊界。
- 模型狀態：POC 候選，待系統負責人審閱；未形成風險接受或安全核准。

## 去識別化範圍

本公開示例未附真實來源碼、原始 API 文件、完整路由、類別／資料表名稱、程式行號、使用者資料、本機絕對路徑、簡報或憑證。案例中的「行動 App」「網站 API」「帳戶／權杖資料」是泛化描述。若需分享更細的證據映射，請使用者在受控內部文件中保存原始對照表。
