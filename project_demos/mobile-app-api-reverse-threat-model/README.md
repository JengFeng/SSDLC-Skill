# Mobile App API 逆向與威脅建模 POC

本案例整理 2026-10-10 的靜態逆向分析與威脅建模示範，展示如何把既有文件、程式行為摘要和 AI 協作結果串成可追溯的安全分析。案例依據真實專案研究成果整理，已將系統名稱、端點、類別、資料表、程式行號與本機路徑泛化；不包含來源碼、憑證或原始簡報。

## 文件導覽

- [範圍與流程](scope-and-flow.md)：建模目標、主要參與者及觀察到的授權流程。
- [資料流程圖](data-flow.md)：外部 App、網站 API、身分服務及資料儲存間的資料流與信任邊界。
- [威脅模型](threat-model.md)：以 STRIDE 整理的候選威脅、優先處理建議與驗證工作。
- [證據與限制](evidence-and-limits.md)：證據類型、分析狀態、未驗證事項及安全公開範圍。

## POC 狀態

本成果是依靜態程式與文件證據建立的候選模型。所有風險排序均為初步討論，不等同弱點確認、正式風險核定或安全測試通過。實際系統負責人仍需確認業務規則、控制措施及驗證結果。
