# Project Demos

此目錄保存可公開分享的 SSDLC-Skill 示範案例。案例以分區文件呈現：範圍與流程、圖表、威脅模型，以及證據與限制。真實專案素材若含內部端點、來源碼、個人資料或本機路徑，須先完成去識別化與審閱，才可放入此處。

## 案例

| 案例 | 說明 | 狀態 |
|---|---|---|
| [Mobile App API 逆向與威脅建模](mobile-app-api-reverse-threat-model/README.md) | 以行動 App 與網站 API 的授權流程示範如何從靜態證據建立流程圖、威脅情境及後續驗證工作。案例名稱、端點與程式細節已泛化。 | POC；待系統負責人審閱 |

## 使用方式

先閱讀各案例的範圍與限制，再查看 DFD 和威脅登錄表。風險排序僅供討論；案例未執行正式環境測試，也不代表任何真實系統已確認存在漏洞。
