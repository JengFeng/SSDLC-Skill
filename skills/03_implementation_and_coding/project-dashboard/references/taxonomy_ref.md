## 混合架構（一個專案含多系統，推薦）
```
{專案資料夾}/
├── _WBS.md                ← 單一真相來源（本 skill 要求）
├── 1_前置作業/            ← 專案管理層（全專案共用）
│   ├── 01_報價文件 / 02_需求規格 / 03_評估報告
├── 2_報告書/              （不分 L2：建議書/期初中末/結案/週月報）
├── 3_簡報檔案/            （不分 L2）
├── 4_會議記錄/
│   ├── 01_定期會議 / 02_需求會議 / 03_臨時會議
├── 6_資安管理/
│   ├── 01_帳號清冊 / 02_主機維護清冊 / 03_原始碼掃描報告
│   ├── 04_主機掃描報告 / 05_資安通報紀錄 / 06_防火牆申請單
├── 7_行政與變更/
│   ├── 01_需求變更單 / 02_驗收確認單 / 03_來往公文
│
└── {系統名稱}/            ← 每個 WBS 系統一個資料夾
    ├── 01_版本開發/  (01_程式碼 / 02_執行檔 / 03_安裝檔)
    ├── 02_技術文件/  (01_系統架構 / 02_API文件 / 03_資料庫設計 / 04_系統設計 / 05_參考資料)
    ├── 03_操作手冊/  (01_使用手冊 / 02_管理者手冊 / 03_FAQ)
    ├── 04_測試文件/  (01_測試案例 / 02_測試報告 / 03_Bug記錄)
    ├── 05_部署維運/  (01_伺服器設定 / 02_部署腳本 / 03_監控工具)
    ├── 06_Demo展示/  (01_展示簡報 / 02_Demo影片 / 03_範例資料)
    └── 07_SDLC交付文件/  (原 5_SDLC 已併入此處)
```

## 健檢要抓的偏離
- WBS 列了系統，但找不到對應 `{系統名稱}/` 資料夾 → **缺**
- 檔案直接躺專案根目錄、或堆在「待確認/」未歸檔 → 列出，建議 file-organizer
- 明顯放錯層（如程式碼放在 2_報告書）→ 提醒
- 不屬本專案的檔 → 建議移到 `其他參考/`

備註：商務文件(報價/合約)、個人學習、其他 為獨立大類，規則較寬。
