# 角色費率參考卡

| 角色 | 一般行情 | 政府小案壓縮 | 商業案／企業 POC |
|---|---|---|---|
| PM / 計畫主持人 | 12-18 | 6-10 | 18-25 |
| SA / 系統分析師 | 12-18 | 6-10 | 18-25 |
| 後端工程師 (PG) | 8-12 | 5-8 | 12-18 |
| 前端 / App 工程師 | 8-12 | 5-8 | 12-18 |
| AI / CV 工程師 | 15-22 | 7-10 | 22-30 |
| LLM / RAG 工程師 | 18-25 | 9-12 | 25-35 |

| QA / 測試 | 8-12 | 5-7 | 12-18 |
| GIS / 領域顧問 | 10-15 | 6-8 | 15-20 |

## 三條鐵律

1. **AI 工程師 ≥ 後端 1.5 倍**
   - PG 5 萬時，CV 至少 7-8 萬，LLM 至少 9-10 萬
   - 若全部統一 5 萬／人月套用 AI，等於賠錢做

2. **政府小案天花板：5-7 萬／人月（適用一般 PG / 前端）**
   - 適合：LineBot 維運、表單系統、報表系統、中小型 web app
   - 不適合：AI 模型訓練、RAG、LLM Prompt 工程

3. **任何含 AI/LLM/GPU 的工項 → 必須走商業案費率**
   - 否則該模組會虧 50-70%
   - 例外：策略性投入 / 卡位後續大案，且要明確標註內部認列虧損
