## 解析順序（skill 拿到「專案名」時）

1. **查上表別名** → 命中即得 project_id。
2. **查無** → 即時打 `GET /EIP/ekb/api/projects.php` ＋ `GET /EIP/progress/api/fetch_projects.php`，用名稱模糊比對。
3. **仍不確定** → 列 2–3 個候選問使用者一次，確認後可順手回寫進本表。

---

## ⚠️ 已知坑（別當成鐵的）

- **這張表會腐化**：新開案、改名、EKB/EIP 改 id 都要維護。用之前若存疑，以即時打 `projects.php` / `fetch_projects.php` 為準。
- **別名是推測的**：上表「別名」欄多由 LINE 群組名 / 工項內容推得，第一次用某別名時最好驗證一次。
- **三套命名不完全一致**：
  - EKB/EIP 用「正式名」（桃園智慧農場）；
  - LINE `extra_json.project` 用「邏輯名」（可能是「桃園水情」「桃園水務局」「越南觀測站」）；
  - 專案**資料夾**名又可能是「115 xx 案」。
  - → 跨源時以 `project_id` 為錨，名稱只給人看。
- **LINE 一案多群**：`list_groups.php?project_id=N` 回的是該案綁定的**多個** source_id，永遠用 source_id 當鍵（群組會改名）。
