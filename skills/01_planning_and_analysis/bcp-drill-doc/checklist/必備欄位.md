# ISMS BCP 演練計畫書 — 必備欄位清單

政府 ISMS 稽核／顧問審核時必檢查項目。Mode A 產生時確認章節齊全，Mode B Review 時逐項比對。

## 封面

- [ ] 機關全名（例：[機構名稱]）
- [ ] 系統正式名稱
- [ ] 「營運持續計畫」字樣
- [ ] 版號（通常為甲方規定）
- [ ] 日期（民國年）

## 目錄

- [ ] 自動產生，頁碼須 F9 更新

## 章節

### 壹、目的
- [ ] 說明演練目標
- [ ] 提及 ISMS、資通安全、災害模擬、備份還原四關鍵概念
- [ ] 結尾交代產出將作為「佐證備份自動化成效與資通系統安全自主檢查之重要依據」

### 貳、系統服務說明 ⭐（顧問退件常見第 2 點）
- [ ] 一、服務對象
  - [ ] 內部單位
  - [ ] 外點站／資料來源端
  - [ ] 研究／決策分析人員
  - [ ] 維運團隊
- [ ] 二、服務重要性
  - [ ] 系統承載的資料類型
  - [ ] 與業務／民眾的關聯
  - [ ] 關鍵資通系統身份
- [ ] 三、中斷可能影響
  - [ ] 資料斷點衝擊
  - [ ] 下游查詢／展示功能影響
  - [ ] 極端氣候／災害期間的特別影響
  - [ ] 跨機關報送影響

### 參、系統架構 ⭐（顧問退件常見第 3 點）
- [ ] 架構圖（嵌入 PNG／SVG）
- [ ] 一、架構組成（逐區塊說明）
- [ ] 二、資料流說明
- [ ] 三、架構圖與演練之對應

### 肆、範圍
- [ ] 參演單位清單
- [ ] 參演系統／服務清單

### 伍、時程
- [ ] 演練時間
- [ ] 演練地點
- [ ] 參演系統／服務

### 陸、參與人員與職責
- [ ] 人員表格（單位／職稱／姓名／職責）
- [ ] 包含本署人員 + 廠商人員（含 PM 若有）

### 柒、執行方式
- [ ] 一、演練情境（災害設定）
- [ ] 二、演練方式（桌上型 / 實機操作 / 混合；Benson 偏好直述不用術語）
- [ ] （一）通報與應變作業
- [ ] （二）實機操作 — 備援環境建置
- [ ] （三）實機操作 — 資料庫還原
- [ ] （四）實機操作 — 應用服務還原
- [ ] （五）整合驗證
- [ ] （六）時間管控指標 ⭐ **MTPD／RTO／RPO 必填**
  - [ ] MTPD 小時數
  - [ ] RTO 小時數
  - [ ] RPO 小時數
  - [ ] 【本次演練情境說明】段（若 RPO 在情境下會超標）
- [ ] （七）備份與還原來源
- [ ] （八）演練平台規格

### 捌、執行作業流程
- [ ] 一、相關人員
  - [ ] 本署人員聯絡資訊
  - [ ] 廠商聯絡資訊
  - [ ] ⚠️ 順序須與「陸、參與人員與職責」表格一致
- [ ] 二、緊急處理程序
  - [ ] （一）資通安全事件通報 — 完成時間：1 小時
  - [ ] （二）緊急應變作業 — **完成時間必填具體分鐘**（例：40 分鐘）
  - [ ] （三）緊急備用作業 — **依 MTPD 時限（填具體小時數）**
  - [ ] （四）復原作業 — **完成時間必填具體分鐘**（例：10 分鐘）
  - [ ] （五）備份或備援資料銷毀作業 — **須具體化方法**
    - [ ] 刪除步驟（OS 層級移除 + 清資源回收筒）
    - [ ] 虛擬硬碟檔案銷毀（.vhd/.vhdx/.vmdk）
    - [ ] 書面佐證（VM 申請表 or 銷毀紀錄表）
    - [ ] 回報與結案
