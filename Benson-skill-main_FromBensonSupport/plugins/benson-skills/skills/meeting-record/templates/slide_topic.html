一、污水管線生成系統龍哥 API / 諺庭 前端
API 策略一條路線 × 呼叫 3 次
作法API 一次只回傳一條路線，前端用不同參數呼叫 3 次 → 得經濟型／水力優化型／探勘型三方案，前端不用改邏輯
演算重力流：起點＝都計區邊界最高點、終點＝污水處理場，往低處推
結論現有 API 暫不再動，先確認能正常接 3 次呼叫
輸入都計區 + 自定範圍
兩種都要：選整個都市計劃區一次生成；或地圖自定範圍（航空城主都計區外要納臨近地區，先選主區再框選擴大合併）
前端結構都計區 → 方案 雙層
改版從「每方案一圖層」改為都計區為頂層、底下掛 3 方案；3 線紅藍綠三色
底圖Google 地圖（不要深色底）、背景顯示都計區、選單變窄
編輯點選方案跳獨立視窗；編輯時複製成新方案、不動原三個（保留比較）
龍哥待補重算 API + 圖層
另開「編輯後重算」API（避障重算）、提供回傳 data 欄位清單、完整道路圖層＋污水處理場獨立圖層（DB 直傳或轉 WKT）
★ 重要分工：法規 vs 水文 兩條檢驗線
法規合規＝俊毅 AI 預審（吃 CSV 計算）　｜　水文合規＝龍哥 API（人孔距 50/25m、管徑、用戶接管 >100m，參考環興顧問指標清單）
