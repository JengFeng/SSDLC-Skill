# 雲端 AI 服務租賃預設配置

## 何時必加

工項含以下任一 → **必須另列「雲端 AI 服務租賃 (首年)」一行**：

- LLM API 推論（RAG 查詢、對話、自動風險評估）
- GPU 推論（CNN、YOLO、SAM、ResNet 等模型 inference）
- ASR / TTS（Google Speech、Azure、Whisper API）
- 向量資料庫 hosting（Pinecone、Qdrant Cloud、Weaviate Cloud）
- 雲端 VM + 物件儲存（後端伺服器、CCTV/影像歸檔）
- SMS gateway（緊急警示自動發送）

## 預設組合（單田場 / 單機關 / 1 年）

| 項目 | 月費 (元) | 年費 (元) | 備註 |
|---|---|---|---|
| LLM API tokens (Claude / OpenAI) | 2,500 | 30,000 | RAG 查詢 + 對話 + 自動風險推論 |
| GPU 推論服務 (CNN + YOLO) | 5,000 | 60,000 | 雲端 GPU 按使用量計費 (Replicate / Modal) |
| 向量資料庫 hosting (Pinecone) | 2,000 | 24,000 | 約 200 萬 tokens 索引規模 |
| 雲端 VM + 物件儲存 | 6,000 | 72,000 | 中型 VM + 1TB 影像歸檔 |
| ASR 語音 API (台語/中文) | 1,000 | 12,000 | 按分鐘計費 |
| SMS 簡訊發送 | 200 | 2,400 | 約 100 則/月 (高風險警示) |
| **合計** | **約 16,700** | **約 200,000** | 落 20 萬／年 |

## 規模調整

| 場域數 | 用戶數 | 建議年費 |
|---|---|---|
| 1 場 / < 10 人 | 內部試辦 | 20 萬 |
| 3-5 場 / 50 人 | 多場域 POC | 50 萬 |
| 10+ 場 / 200+ 人 | 縣市級部署 | 100-200 萬 |

## 替代方案：硬體買斷（Capex 化 OPEX）

若業主希望**主機放在自家機房（資料不出場）**，可改買斷 GPU 主機：

| 項目 | 一次性費 |
|---|---|
| RTX 4090 推論主機 (2U) | 80,000-120,000 |
| 4TB NAS | 30,000-40,000 |
| **合計** | **約 15 萬** |

→ 第 2 年起雲端費可降至 **約 13 萬／年**（只剩 LLM API + 向量 DB + SMS）

→ 適合政府案資安要求（資料不出場）的場景

## 寫法範例（精簡版）

放在開發費 5 個工項之後、合計之前：

| # | 內容 | 單位 | 數量 | 單價 | 總價 |
|---|---|---|---|---|---|
| 6 | 雲端 AI 服務租賃 (首年) | 年 | 1 | 200,000 | 200,000 |

備註欄寫：「LLM API tokens、GPU 推論服務、向量資料庫 hosting、雲端 VM 與物件儲存、ASR 語音 API、SMS 簡訊發送（首年合計）」

## 反模式

- **不要**把 LLM API / GPU 算力塞進開發人月 → 沒算到持續燒的 token / 算力
- **不要**忘了業主第 2 年起也要繼續付（除非有買斷硬體）
- **不要**把雲端費用塞進「廠商管理費」吸收 → 管理費是利潤、不是 OPEX 緩衝
