# 威脅建模本機整併預覽

## 設定與生命週期

**安全基準已啟用，或使用者明確要求／選取威脅建模時，威脅模型為必要交付物；其餘情況為選用。**

```mermaid
flowchart LR
  P1[01：資產、安全需求與建模規劃] --> P2[02：第一版模型與審查]
  P2 --> P3[03：控制實作與追溯]
  P3 --> P4[04：驗證改善與剩餘風險]
  P4 --> P5[05：確認實際部署]
  P5 --> P6[06：事故與變更觸發更新]
  P6 -->|受影響設計| P2
```

Phase 02 完成模型不代表控制已驗證，Phase 04 驗證完成也不代表模型永久停止更新。
