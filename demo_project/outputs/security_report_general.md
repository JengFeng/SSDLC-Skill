## 普級重點風險 (TOP 5)

1. 🔴 **無身分驗證**：系統完全開放，任何人可存取 CRUD 功能
2. 🔴 **debug=True 上線**：洩漏 stack trace 與內部資訊
3. 🔴 **secret_key 明文硬編碼**：session 可被偽造
4. 🟠 **無 HTTPS**：所有資料明文傳輸
5. 🟠 **無備份機制**：單一 SQLite 檔案，無災難復原能力
