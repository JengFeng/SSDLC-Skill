# 員工基本資料管理系統——需求訪談紀錄
**日期：** 2026年6月29日

**訪談人員：** 系統分析組（SA）、人力資源部主管（HRM）、人力資源部專員（HR Specialist）

**紀錄人：** 系統分析小組

## 訪談對話實錄
**SA：** 各位好，今天主要是想跟 HR 單位確認「員工基本資料管理系統」的核心需求。我們希望了解現行流程的痛點，以及新系統需要具備哪些功能。

**HRM：** 好的。目前我們最大的痛點是資料太過分散。新進員工報到時，基本資料、學經歷、證照都在 Excel 裡；但排班和薪資又在別的系統，甚至有些紙本資料還要手動建檔，常發生打錯字或欄位不一致的情況。

**HR Specialist：** 對，而且每次勞動法規更新（例如勞健保級距變更），我們都要人工去核對每一筆資料，非常耗時。我們希望新系統能有**完整的員工生命週期紀錄**，從報到、調職、升遷到離職，都能在同一個介面看到。

**SA：** 明白，這屬於核心的「員工主檔管理」。那在權限控管方面有什麼考量嗎？畢竟員工資料包含身分證字號、薪資等敏感資訊。

**HRM：** 這非常重要！**權限必須要分層**。一般員工只能看自己和修改部分個人聯絡資訊（例如手機、緊急聯絡人）；HR 專員可以維護所有人的基本資料；但「薪資」和「人事評核」的欄位，只有我（主管）和高階高層才能檢視或修改。

**HR Specialist：** 另外，主管們常需要看一些統計報表，例如各單位的離職率、年資分佈、或是當月壽星名單。如果系統能自動產出這些報表，並支援匯出 Excel 就太好了。

**SA：** 沒問題，報表與統計圖表我們會納入功能。那在系統效能、穩定性或安全法規上有特別的要求嗎？

**HRM：** 安全性絕對是第一。因為包含大量個資，系統必須符合台灣的《個人資料保護法》規範，傳輸和儲存都要加密。另外，系統要跟我們現有的 Windows Active Directory (AD) 整合，員工直接用電腦帳密登入即可，不用再記一組密碼。

**HR Specialist：** 還有，因為全公司上下都會使用這個系統（包含行動裝置查詢），我們希望介面要直覺，查詢員工資料的速度要快，不要轉半天網頁才跑出來。

**SA：** 好的，這屬於非功能需求。我們會確保查詢回應時間在合理範圍內，並做好 AD 整合與個資加密。今天的訪談重點我們已經記錄下來，接下來我們會將這些需求整理成具體的系統規格清單。

## 訪談需求整理：功能需求 (Functional Requirements)
根據訪談內容，系統必須具備以下核心功能：

### 1. 員工主檔與生命週期管理

- **新進報到建檔：** 支援 HR 輸入新進員工基本資訊（姓名、身分證字號、出生年月日、到職日、部門、職稱等）。
- **異動歷史紀錄：** 系統須自動記錄員工的職務調動、升遷、調薪及離職等歷史軌跡，不可直接覆蓋歷史資料。
- **學經歷與證照維護：** 支援多筆學歷、工作經歷及專業證照的登錄與附件上傳功能。

### 2. 自助服務與權限控管 (ESS)

- **員工自我維護：** 開放一般員工登入修改「非機密性」欄位（如通訊地址、手機號碼、緊急聯絡人）。
- **角色權限劃分（RBAC）：** 
  - **一般員工：** 僅能檢視個人資料、修改限定聯絡欄位。
  - **HR 專員：** 可維護全體員工基本資料、學經歷，無薪資查看權限。
  - **HR 主管/高階主管：** 具備全系統所有欄位（含薪資、人事評核、離職原因）的完整讀寫權限。

### 3. 報表與統計分析

- **人事報表生成：** 系統內建「年資分佈圖」、「部門人力結構圖」、「每月壽星清單」及「離職率統計」。
- **資料匯出：** 所有查詢結果與報表皆須支援匯出為標準 Excel (`.xlsx`) 格式。

## 訪談需求整理：非功能需求 (Non-Functional Requirements)
為確保系統的安全性、穩定性與實用性，須滿足以下技術與品質規範：

### 1. 安全性與法規遵從 (Security)

- **個資保護法相容：** 系統架構與資料庫設計須完全符合台灣《個人資料保護法》規範。
- **資料加密：** 敏感欄位（如身分證字號、薪資、銀行帳號）於資料庫儲存時須進行加密處理；全站傳輸須強制使用 HTTPS 加密協定。
- **稽核軌跡 (Audit Trail)：** 系統須自動記錄所有使用者對員工資料的「新增、修改、刪除、檢視」行為，日誌（Log）須包含帳號、時間、IP 與異動前後內容，且日誌不可竄改。

### 2. 系統整合與驗證 (Integration)

- **單一登入 (SSO)：** 系統須與企業現有的 **Windows Active Directory (AD)** 進行驗證整合，員工登入時免除重複輸入密碼之不便。

### 3. 效能與可用性 (Performance & Usability)

- **回應時間：** 在一般網路環境下，單筆員工資料查詢與網頁載入時間須於 **2 秒內**完成；複雜報表產出時間須於 **5 秒內**完成。
- **響應式網頁設計 (RWD)：** 系統介面須支援跨平台檢視，包含 PC 瀏覽器、平板及智慧型手機，以利員工使用行動裝置進行自助查詢。
