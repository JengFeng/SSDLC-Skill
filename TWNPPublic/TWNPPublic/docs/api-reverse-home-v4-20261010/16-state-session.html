瀏覽器的授權與 Session 狀態

外部帳密授權只核發金鑰；LoginAPP 才建立網站登入 Session。取消授權、Logout 與 Session 不存在有不同結果。

推導狀態，不是程式 enum。Session 閒置期限設定為 3600 秒且使用記憶體 cache；實際手機 Cookie／節點重啟後行為需執行驗證。Logout 僅移除 UserName，沒有清除 Token 或全部 Session。
