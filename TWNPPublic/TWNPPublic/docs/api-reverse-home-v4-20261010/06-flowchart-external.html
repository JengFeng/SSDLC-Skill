圖面預設依頁面可用寬度自動 fit，視窗大小改變時會重新調整。文字大小按鈕以目前圖框寬度為基準；超過 100% 時可左右捲動。來源編號不是步驟或錯誤碼；較小框的來源放在滑鼠提示與下方證據表。

CSRF 由框架先處理，失敗不進入 Action。驗證碼在實際 ValidateCaptcha 呼叫時立即移除；帳密錯誤後也要重新取得驗證碼。各失敗節點不會回傳 1004 callback。
