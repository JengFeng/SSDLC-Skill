# Functional Neutral

- 沒有風格就是風格。刻意讓自己保持中性，讓品牌色疊上去不衝突。
- 邊框極細（0.5px），圓角保守。
- 無裝飾性陰影，陰影只用於功能性浮層。
- 留白是主要的視覺語言，讓內容和功能有足夠的空間呼吸。
- 以內容為主，設計元素不搶戲。

## Class name Guidelines

classname 命名**neutral**: 例如 .card-neutral、.btn-neutral

## Recommend

component: All
