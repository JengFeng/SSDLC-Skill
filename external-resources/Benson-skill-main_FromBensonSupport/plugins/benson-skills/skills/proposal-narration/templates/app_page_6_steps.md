# APP / 服務頁文案模板（6 段式）

User 對 APP / 服務介紹頁第一個抱怨永遠是「太薄弱」「太普通」「沒打動人」。
任何「服務介紹」「功能展示」「儀表板介紹」「報表頁」頁面，**一律套此模板**。

---

## 6 段式結構

```
[1. 過去痛點]（具體場景：時間 + 動作 + 工具）
過去農民每天清晨 5 點，就要拿著手電筒繞田一圈，
靠經驗判斷今天該不該下藥。

[2. 現在的解法]（時間對比 + 具體操作）
現在打開 APP 只要三秒——綠燈安心、黃燈留意、橘燈立刻處理。

[3. AI 的隱性 24/7 工作]（強調 AI 在背後做苦工）
背後是 AI 24 小時不眠不休幫你看田，
農民只要會看顏色，就能管 3.4 公頃。

[4. 量化數據 + 具體功能]
中段三項即時數值——株高、綠覆率、葉色等級，
全部影像辨識自動算，不用人工量。

[5. wow 因子]（最強亮點 + 反向操作）
最重要的是，當風險升級的瞬間，系統會主動透過 LINE 推送通知到你手機——
你不用守著 APP，AI 會主動找你。

[6. 對比結尾]（從 X 到 Y 的飛躍）
從『巡田猜風險』，到『AI 主動通知』——
這就是農業真正的數位升級。
```

---

## ❌ 反例：功能列表式（會被退稿）

```
本 APP 提供三大功能：
1. 三色燈號顯示
2. AI 即時數值
3. 推送通知
```
平淡無感，缺場景、缺 wow、缺對比。**永遠不要這樣寫**。

## 套用在不同主題的範例

### 系統儀表板介紹（套 6 段式）
```
[1] 過去管理者每天要打開 5 個系統、查 30 個指標，半小時才能拼出全景。
[2] 現在打開儀表板 5 秒——綠/黃/紅燈一目了然，異常自動標紅。
[3] 背後是 AI 把 5 個系統的資料即時抓取、清洗、評分。
[4] 14 個關鍵指標、3 個風險評分、即時更新。
[5] 異常時自動推 LINE / Email / Teams 給負責人，不用守著螢幕。
[6] 從『查資料』到『被通知』——管理效率質的飛躍。
```

### 報表頁（套 6 段式）
```
[1] 過去寫週報要花一個下午——抓資料、整理、套圖、寫文。
[2] 現在打開報表頁，按一下「匯出本週」，PDF 30 秒打包好。
[3] AI 自動把當週重點抓出來，連敘述都寫好初稿。
[4] 含 8 張圖表、3 個 KPI、12 條決策軌跡。
[5] 報表還能直接 Email / 上傳雲端 / 分享到群組——不用手動寄。
[6] 從『寫報表』到『審報表』——你只要審核就好。
```

---

## 寫作 checklist

寫完一頁旁白，逐條檢查：

- [ ] 有「過去痛點」具體場景嗎？（不是抽象說「過去很麻煩」）
- [ ] 有「時間 / 數量」對比嗎？（30 分鐘 → 3 秒）
- [ ] 有提到 AI 在「背後」做事嗎？（隱性工作）
- [ ] 有量化數據嗎？（坪數 / 件數 / 百分比 / 速度）
- [ ] 有 wow 因子嗎？（反向操作 / 主動通知 / 一鍵搞定）
- [ ] 結尾有「從 X 到 Y」對比嗎？

6 條全勾 → 過。少一條 → 重寫。
