## 非軟體面向安全因子（構面 8）

以下項目不屬於 SSDLC 軟體開發範圍，但為資通系統的**外部安全前提**：

| 面向 | 項目數 | 內容 |
|------|:--:|------|
| 組織管理 | 6 項 | 資安專責人員配置、通識教育訓練（每年3hr）、專業證照（A:4/B:2/C:1張）、職能證書、內部稽核（A:2次/年）、治理成熟度評估 |
| 管理制度 | 3 項 | CNS 27001/ISO 27001 導入與第三方驗證、BCP 業務持續運作演練、限制危害國家資通安全產品 |
| 實體環境 | 3 項 | 機房門禁管制、溫溼度/消防/電力備援監控、實體媒體銷毀程序 |
| 供應鏈 | 2 項 | 委外廠商資安評鑑、第三方獨立安全檢測（滲透測試） |

> 詳細內容請參閱 `references/08_organizational.md`。

## 資通安全責任等級對照

| 等級 | 檢核表檔案 | 軟體控制措施 | 非軟體因子 |
|------|----------|:--:|:--:|
| 普 (General) | `assets/checklist_general.md` | 58 項 | 依等級要求 |
| 中 (Medium)  | `assets/checklist_medium.md`  | 70 項 | 依等級要求 |
| 高 (High)    | `assets/checklist_high.md`    | 80 項 | 依等級要求 |

各等級檢核表均包含「資訊使用管理稽核項目」（臺北市政府 15 類稽核項目）。

> **控制措施數量說明**：軟體控制措施總數 80 項，係依據數位發展部資通安全署
> 《資通系統防護基準驗證實務 v1.3》第 4 頁原文：「7 個構面、27 類控制措施類別之
> **80 項控制措施**」。三等級採累進式設計，非軟體因子 14 項為獨立補充，不計入軟體總數。

## 使用方式

### 雙軌設計

| 模式 | 指令 | 說明 |
|------|------|------|
| **主動融入** | `@init` 時選用 | 依選定等級將安全控制措施直接嵌入各 SSDLC 階段 PDCA 閉環 |
| **事後稽核** | `@security-check <等級>` | 階段完成後逐項比對檢核，產出符合/不符合報告 |

### 腳本生成

```bash
python scripts/generate_checklist.py general   # 普級
python scripts/generate_checklist.py medium    # 中級
python scripts/generate_checklist.py high      # 高級
```
