# 構面 7：系統與資訊完整性 (System & Information Integrity)

> 資料來源：資通系統防護基準驗證實務 v1.3 §2.7

## 控制措施類別

### 7.1 漏洞修復（項次 76-78）

| 項次 | 控制措施 | 適用等級 |
|------|---------|:---:|
| 76 | 應定期確認資通系統相關漏洞修復之狀態 | 普/中/高 |
| 77 | 應針對已知漏洞進行修補或採取補償性控制措施 | 普/中/高 |
| 78 | 應建立自動化更新機制（WSUS / yum-cron / unattended-upgrades） | 中/高 |

**修補時程建議**：
- 嚴重（Critical）：7 天內
- 高（High）：30 天內
- 中（Medium）：90 天內
- 低（Low）：180 天內

### 7.2 資通系統監控（項次 79-80）

| 項次 | 控制措施 | 適用等級 |
|------|---------|:---:|
| 79 | 應監控資通系統之使用情形，偵測異常行為 | 普/中/高 |
| 80 | 應針對資安事件建立通報機制 | 普/中/高 |

**監控項目**：
- 系統連線監控（儀表板）
- WAF 偵測與分析
- 異常流量警示
- 目錄檔案完整性監控（File Integrity Monitoring）

**資安通報要求**（資通安全管理法）：
- 資安事件發生後 1 小時內通報
- 依等級進行分級通報（1~4 級）

### 7.3 軟體及資訊完整性（項次 81-82）

| 項次 | 控制措施 | 適用等級 |
|------|---------|:---:|
| 81 | 應驗證輸入資料之合法性（防範 SQL Injection / XSS） | 普/中/高 |
| 82 | 應使用防毒軟體或惡意軟體防護機制 | 普/中/高 |

**輸入驗證要點**：
- 白名單驗證優先於黑名單
- 參數化查詢（Parameterized Query）防範 SQL Injection
- 輸出編碼（HTML Encoding）防範 XSS
- 檔案上傳驗證（類型、大小、病毒掃描）

## 資訊使用管理稽核項目（臺北市政府，共 15 類）

以下稽核項目對應至本構面之系統監控與可歸責性：

| 類別 | 稽核項目 |
|------|---------|
| 系統查詢軌跡 | 是否建立及啟動系統查詢軌跡紀錄檔（Log）並保存 |
| 系統查詢軌跡 | 紀錄檔是否定期備份轉出後保存 |
| 系統查詢軌跡 | 是否有專人隨時檢視紀錄 |
| 系統存取異常 | 登入次數是否正常 |
| 系統存取異常 | 登入失敗次數是否正常（連續失敗警示） |
| 系統存取異常 | 登入時段是否正常（非勤務時間登入檢核） |
| 系統存取異常 | 使用者 IP 位址是否正常 |
| 系統存取異常 | 帳號密碼是否有共用或交由他人使用 |
| 系統存取異常 | 是否以離（休）職員工帳號登入 |
| 系統存取異常 | 單次使用系統時間是否正常 |
| 系統存取異常 | 累計使用系統時間是否正常 |
| 系統存取異常 | 使用者查詢筆數是否正常 |
| 系統存取異常 | 是否依規定登載案號或查詢事由 |
| 系統存取異常 | 查詢內容與登載事由是否相符 |
| 通報機制 | 是否建立系統存取異常狀況通報機制 |

## SSDLC 階段對應

- **Phase 3 開發編碼**：輸入驗證（項次 81）、防範 Injection 攻擊
- **Phase 4 測試驗證**：弱點掃描、修補驗證
- **Phase 5 部署發布**：防毒軟體配置、自動更新設定（項次 78）
- **Phase 6 維護監控**：系統監控儀表板（項次 79）、事件通報（項次 80）、定期修補
