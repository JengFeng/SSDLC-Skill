# 構面 8：組織、實體與供應鏈安全（非軟體開發因子）

> 本文件整理資通系統防護基準中**不屬於 SSDLC 軟體開發範圍**的安全控制措施。
> 這些項目涉及組織管理、實體環境、供應鏈治理，為軟體系統的**外部安全前提**，
> 雖不由開發團隊直接實作，但管理者應於專案啟動前評估並配套執行。

---

## 一、組織管理面（6 項）

### 1.1 資安專責人員配置

| 等級 | 人數要求 | 說明 |
|:---:|:--:|------|
| A | 4 人（專職） | 初次受核定或等級變更後一年內配置 |
| B | 2 人（專職） | 同上 |
| C | 1 人（專職） | 同上 |

> 專職人員定義與業務範圍請見資通安全管理法常見問題。

| 一般使用者及主管 | 每年 3 小時以上（通識） | 全體人員 |

### 1.3 資安專業證照

| 等級 | 證照數 | 說明 |

| B | 2 張以上 | 同上，持續維持有效性 |
| C | 1 張以上 | 同上 |

> 參考：資安人才培訓服務網、資通安全管理法常見問題。

### 1.4 資安職能評量證書

| 等級 | 證書數 | 說明 |
|:---:|:--:|------|

| B | 2 張以上 | 同上 |

### 1.5 內部資通安全稽核

| 等級 | 頻率 | 說明 |

### 1.6 資安治理成熟度評估

## 二、管理制度面（3 項）

### 2.1 CNS 27001 / ISO 27001 導入與驗證

| 等級 | 導入 | 第三方驗證 |
|:---:|:--|:--|
| A / B | 二年內全部核心系統導入 | 三年內完成公正第三方驗證，持續維持有效性 |
| C | 二年內全部核心系統導入 | 持續維持導入（不需第三方驗證） |

> 導入可參考 CNS 27001 或 ISO 27001 相關制度與控制措施要求自行或委外導入。
> 驗證委外由第三方驗證公司辦理，RFP 文件可參考技服中心政府機關 ISMS 第三方驗證 RFP。

### 2.2 業務持續運作演練

| 等級 | 頻率 | 說明 |
|:---:|:--:|------|
| A | 每年 1 次 | 全部核心資通系統 |
| B / C | 每 2 年 1 次 | 全部核心資通系統 |

> 參考 CNS 27001 或 ISO 27001 相關業務持續運作之程序書，亦可參考技服中心 100 年度營運持續管理參考指引。

### 2.3 限制使用危害國家資通安全產品

| 要求 | 說明 |
|------|------|
| 不得採購及使用 | 除因業務需求且無其他替代方案外 |
| 專案方式購置 | 須具體敘明理由，經主管機關核可 |
| 列冊管理 | 不得與公務網路環境介接 |

> 參考：各機關對危害國家資通安全產品限制使用原則。

## 三、實體環境面（3 項）

| 項目 | 說明 |
|------|------|
| 機房門禁管制 | 人員進出登記、門禁卡/生物辨識、訪客陪同 |
| 環境監控 | 溫溼度、消防、電力備援（UPS/發電機）、漏水偵測 |
| 實體媒體銷毀 | 硬碟消磁/破壞、紙本碎紙、報廢設備安全清除 |

> 雖非軟體範疇，但實體安全為資訊安全的基礎前提。

---

## 四、供應鏈與委外面（2 項）

| 項目 | 說明 |
|------|------|
| 委外廠商資安評鑑 | 採購前評估廠商資安能力、要求提供資安認證、契約納入資安條款 |
| 第三方獨立安全檢測 | 高級系統應委由獨立第三方執行滲透測試與資安稽核 |

## 五、與 SSDLC 階段的關係

```
┌────────────────────────────────────────────┐
│  組織管理面 (人力/訓練/證照/稽核/治理)       │ ← 專案啟動前評估
├────────────────────────────────────────────┤
│  管理制度面 (ISO 27001/BCP演練/產品限制)     │ ← Phase 0 前置作業
├────────────────────────────────────────────┤
│  SSDLC 6 階段 (構面 1-7, 80項軟體控制措施)   │ ← 本框架核心範圍
├────────────────────────────────────────────┤
│  實體環境面 (機房/監控/銷毀)                │ ← 部署環境配套
├────────────────────────────────────────────┤
│  供應鏈面 (委外評鑑/第三方測試)              │ ← Phase 5 部署前確認
└────────────────────────────────────────────┘
```

## 六、建議檢核時機

| 時機 | 檢核項目 |
|------|---------|
| 專案啟動前 | 組織管理面 (1.1~1.6) + 管理制度面 (2.1~2.3) |
| Phase 5 部署前 | 實體環境面 + 供應鏈面 |
| 年度定期 | 內部稽核、BCP 演練、治理成熟度評估 |
