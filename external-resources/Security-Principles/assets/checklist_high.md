## 🔴 高級新增項目（10 項）

### 構面 2：事件日誌與可歸責性 — 強化
- [ ] 項次 22-高：日誌處理失效應自動觸發緊急通報（SIEM 整合）

### 構面 3：營運持續計畫 — 強化
- [ ] 項次 34-高：核心系統應建立即時（Real-time）異地備援機制
- [ ] 項次 35-高：每半年執行一次備援切換演練（含災難還原劇本）

### 構面 4：識別與鑑別 — 強化
- [ ] 項次 37-高：應使用硬體安全金鑰（FIDO2）或生物辨識之多因子驗證
- [ ] 項次 47-高：密碼儲存應使用 Argon2id 並加鹽，禁止使用 MD5/SHA-1

### 構面 5：系統與服務獲得 — 強化
- [ ] 項次 57-高：滲透測試應由第三方獨立團隊執行
- [ ] 項次 60-高：SBOM 應自動化掃描並整合至 CI/CD Pipeline

### 構面 6：系統與通訊保護 — 強化
- [ ] 項次 72：應考量後量子加密（Post-Quantum Cryptography, PQC）支援
- [ ] 項次 75：應使用金鑰管理機制（HSM 或金鑰保管服務）保護加密金鑰

### 構面 7：系統與資訊完整性 — 強化
- [ ] 項次 79-高：應部署 SIEM（Security Information and Event Management）系統
- [ ] 項次 80-高：資安事件應於 1 小時內完成通報

## 🔴 高級專屬：資通安全責任等級 A 級額外要求

| 要求項目 | 執行頻率 |
|---------|:---|
| 資安專責人員配置 4 人（專職） | 一年內完成 |
| 內部資通安全稽核 | 每年二次 |
| 業務持續運作演練（全部核心系統） | 每年一次 |
| 資安治理成熟度評估 | 每年一次 |
| CNS 27001 / ISO 27001 導入 + 第三方驗證 | 二年內導入，三年內完成驗證 |
| 限制使用危害國家資通安全產品 | 持續 |
