# 資通系統防護基準檢核表 — 普級 (General)

> 適用對象：普級資通系統
> 資料來源：數位發展部資通安全署《資通系統防護基準驗證實務 v1.3》
> 控制措施總數：58 項

---

## 構面 1：存取控制

### 帳號管理
- [ ] 項次 1：建立帳號管理機制（申請、建立、修改、啟用、停用、刪除程序）
- [ ] 項次 2：已逾期之臨時或緊急帳號應刪除或禁用
- [ ] 項次 3：資通系統閒置帳號應禁用（180 天未登入）
- [ ] 項次 4：定期審核帳號之申請、建立、修改、啟用、停用及刪除

### 最小權限
- [ ] 項次 9：採最小權限原則，僅允許完成指派任務所需之授權存取

### 遠端存取
- [ ] 項次 10：每一種遠端存取類型均應先取得授權並文件化
- [ ] 項次 11：使用者之權限檢查作業應於伺服器端完成
- [ ] 項次 12：應監控遠端存取內部網段或後臺之連線
- [ ] 項次 13：應採用加密機制（HTTPS/SSH）
- [ ] 項次 14：遠端存取來源應為機關已預先定義之存取控制點

## 構面 2：事件日誌與可歸責性

### 記錄事件
- [ ] 項次 15：訂定日誌記錄時間週期及留存政策，保留日誌至少六個月
- [ ] 項次 16：確保資通系統有記錄特定事件之功能
- [ ] 項次 17：應記錄管理者帳號所執行之各項功能

### 日誌紀錄內容
- [ ] 項次 19：日誌應包含事件類型、時間、位置、使用者身分，格式一致

### 日誌儲存容量
- [ ] 項次 20：依據日誌儲存需求，配置所需之儲存容量

### 日誌處理失效之回應
- [ ] 項次 21：日誌處理失效時，應採取適當之行動

### 時戳及校時
- [ ] 項次 23：日誌時戳可對應到 UTC 或 GMT
- [ ] 項次 24：系統內部時鐘應定期與基準時間源同步（NTP）

### 日誌資訊之保護
- [ ] 項次 25：對日誌之存取管理，僅限於有權限之使用者

---

## 構面 3：營運持續計畫

### 資料備份
- [ ] 項次 28：訂定資料可容忍損失之時間要求（RPO）
- [ ] 項次 29：執行資料備份

### 系統備援
- [ ] 項次 33：訂定系統從中斷後至恢復服務之最大可容忍中斷時間（RTO）

---

## 構面 4：識別與鑑別

### 使用者之識別與鑑別
- [ ] 項次 36：應識別及鑑別使用者，禁止共用帳號

### 身分驗證管理
- [ ] 項次 38：使用預設密碼初次登入後應立即變更
- [ ] 項次 39：身分驗證相關資訊不以明文傳輸
- [ ] 項次 40：帳戶鎖定機制（失敗 5 次後至少 15 分鐘內不允許嘗試）
- [ ] 項次 41：強制最低密碼複雜度，依效期規定變更密碼
- [ ] 項次 42：密碼變更時不可與前三次相同
- [ ] 項次 43：外部使用者密碼規範由機關自行辦理

### 鑑別資訊保護
- [ ] 項次 46：應遮蔽鑑別過程中之資訊（密碼以星號顯示）
- [ ] 項次 47：資料庫密碼欄位不得明文儲存

## 構面 5：系統與服務獲得

### 需求階段
- [ ] 項次 48：針對系統安全需求（機密性、可用性、完整性）進行確認

### 開發階段
- [ ] 項次 51：應針對安全需求實作必要控制措施
- [ ] 項次 52：應注意避免軟體常見漏洞（OWASP Top 10）
- [ ] 項次 53：錯誤時僅顯示簡短訊息及代碼，不包含詳細錯誤

### 測試階段
- [ ] 項次 56：執行「弱點掃描」安全檢測

### 部署與維運階段
- [ ] 項次 58：於部署環境中針對資安威脅進行更新與修補

### 委外階段
- [ ] 項次 61：委外開發 RFP 應包含資安需求規範
- [ ] 項次 62：委外開發契約應納入資安要求及違約條款

### 獲得程序
- [ ] 項次 64：系統採購或獲得時應確認資安需求並進行安全測試

### 系統文件
- [ ] 項次 65：應建立系統管理文件（含安全設定、操作手冊）
- [ ] 項次 66：應建立系統相關文件儲存與管理機制

## 構面 6：系統與通訊保護

### 傳輸之機密性與完整性
- [ ] 項次 67：身分驗證及資料傳輸應採用加密協定（HTTPS/TLS 1.2+）
- [ ] 項次 68：應使用公鑰憑證保護傳輸安全
- [ ] 項次 69：遠端管理應採用加密連線

### 資料儲存之安全
- [ ] 項次 73：資料庫連線字串不得明文儲存

---

## 構面 7：系統與資訊完整性

### 漏洞修復
- [ ] 項次 76：應定期確認系統相關漏洞修復之狀態
- [ ] 項次 77：應針對已知漏洞進行修補或採取補償性控制措施

### 資通系統監控
- [ ] 項次 79：應監控系統使用情形，偵測異常行為
- [ ] 項次 80：應針對資安事件建立通報機制

### 軟體及資訊完整性
- [ ] 項次 81：應驗證輸入資料之合法性（SQL Injection / XSS 防範）
- [ ] 項次 82：應使用防毒軟體或惡意軟體防護機制
